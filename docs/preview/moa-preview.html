Preview interativo do Moa Media Player (maquete)

Maquete para você avaliar o desenho. Não toca som e não é o código final. Tudo vale a regra de um clique, alvos de 64 px ou mais, letra base de 20 px, contraste de 7:1 ou mais (conferido) e tema claro. Use os controles abaixo para comparar as variantes que ainda estão em aberto.

Já decidido: o “+” mostra as capas dos discos; “Apagar de vez” só existe dentro da Lixeira; tamanho da letra e cores para daltonismo ficam em “Configurações”. Ainda em aberto (a primeira opção de cada grupo é o padrão):

Atenção: a barra de título escura (–, □, ✕) não é desenho nosso: é a do sistema, e o X dela é pequeno (bem abaixo de 64 px; tamanho exato a confirmar no Cinnamon). Isso é uma decisão a tomar: aceitar o X do sistema ou desenhar um cabeçalho próprio com um X grande.
